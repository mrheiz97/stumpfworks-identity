# StumpfWorks Identity v1.13.2

- Adds the opt-in Active Directory user creation path with a dedicated creator role, explicit plan confirmation, durable audit and authenticated receipts. The operation creates disabled accounts in a fixed scope.
- Adds peer-authenticated executor transport and fixed-command SSH relay support. The web endpoint, executor and relay are disabled by default.
- Documents and tests the Samba write boundaries, UPN allocation, journal recovery and rollback. Profile CAS remains gated.
- Keeps the existing PostgreSQL application schema and client update catalog format.

Deployment and AD write activation require separate acceptance.
