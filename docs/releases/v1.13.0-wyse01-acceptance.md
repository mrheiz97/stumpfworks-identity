# WYSE01 v1.13.0 status/updater deployment

Executed 2026-11-01 after explicit approval of the prepared WYSE01 two-phase
maintenance window. Only the **status reporter and updater** were upgraded.
No greeter/PAM/device tool/worker/unit package was installed. MOBILE01 was not
contacted or changed. LOGIN01 had no binary, configuration, service, catalog,
target-version or client-policy change; it continued receiving normal status
reports and was queried read-only to verify delivery.

fingerprint were rechecked before a new root-only maintenance directory was

`/root/wyse01-v1130-rollback-20261101T182200Z` (0700).
Its **39 manifest files** were verified against live source bytes and recorded

The status timer was paused and any active report drained for Phase A. A
hash-verified executable copy of the original 1.4.1-dev updater was retained in

signature check skipped or recovery pre-hook disabled. This supervised bootstrap
is bounded to the observed predecessor and exact signed payloads; it is not a
